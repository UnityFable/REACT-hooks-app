# Clase avanzada de uso de Hooks en React

En este proyecto se estudian algunos de los Hooks disponibles en React. Entre ellos están:

- useState
- useEffect
- useRef
- useReducer
- useMemo
- useCallback
- useOptimistic
- useTransition

Tambien se profundiza en algunos temas referentes a los Hooks:

- React.memo
- Suspense
- use
